Kako dobiti .eml fajl?

  • Gmail (web): otvori mail → ⋮ (tri tačke) → Download message. Ili Show original → kopiraj sve i zalijepi gore.
  • Outlook (web / novi Outlook): otvori mail → ⋯ → Save / Download (.eml). Za izvorni kod: ⋯ → View → View message source.
  • Telefon: proslijedi mail kao prilog na adresu za provjeru (ako je podešena), ili kopiraj tekst.

Samo zalijepljen tekst (bez zaglavlja) daje slabiju analizu – nema provjere pošiljaoca, autentičnosti ni priloga.
